# Architecture Decision Records

本目录记录 Flow Hub 的关键架构决策。

## 格式

每个决策一个文件，文件名格式：`NNNN-slug.md`。采用 [Michael Nygard 的 ADR 格式](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions)。
